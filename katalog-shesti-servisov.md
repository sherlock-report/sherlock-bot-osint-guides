# Каталог ботов для пробива: шесть карточек и их назначения

На BOT-PROBIVA.ONLINE представлены шесть карточек Telegram-сервисов. Следующая таблица пересказывает направления, обозначенные на главной странице каталога на дату проверки. Она не является независимым тестом этих инструментов.

| Название | Что отмечает каталог |
| --- | --- |
| SHERLOCK BOT | Поиск по открытым источникам |
| Vector BOT | Поиск по имени, email и автомобилю |
| Telelog / Funstat | Аналитика Telegram |
| ENIGMA SEARCH BOT | Социальные сети и Telegram ID |
| VOID BOT | Возможности предлагается уточнять в меню |
| Dyxless | Возможности предлагается уточнять в меню |

[Открыть каталог и описания сервисов](https://bot-probiva.online/).

## Как читать эту таблицу

Направление работы не подтверждает доступность каждой отдельной функции. Например, формулировка «аналитика Telegram» сама по себе не объясняет, какие именно каналы, периоды и показатели доступны.

Проверяйте детализацию в описании и действующем интерфейсе сервиса. Если конкретный режим не указан, не считайте его включённым по умолчанию.

## Что сравнить дополнительно

Посмотрите стоимость запроса, ограничения, наличие исходных ссылок и правила использования результата. Отдельно выясните, можно ли увидеть дату сведений.

## Почему здесь нет мест в рейтинге

Чтобы ранжировать сервисы, нужны одинаковые тестовые задачи, измеримые критерии и зафиксированные результаты. Этот материал описывает навигацию каталога. Порядок строк не выражает предпочтение и не подтверждает превосходство одного бота над другим.
