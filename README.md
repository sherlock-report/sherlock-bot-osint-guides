## Что проверено

На 2026-09-27 проверены главная страница BOT-PROBIVA.ONLINE и описание SHERLOCK BOT. На странице Шерлока заявлен поиск по открытым источникам, включая username. Работоспособность запросов, тарифы и качество выдачи внутри ботов не тестировались.

«Шерлок Репорт» здесь обозначает справочные материалы аккаунта sherlock-report. Мы не выводим юридическую принадлежность сервисов из совпадения названий. Таблицы проверки и примеры отчётов — редакционные материалы, а не образцы реальной выдачи бота.

## Редакционные принципы

- Отделять описание сервиса от проверенного результата.
- Указывать ограничения и не обещать поиск любых данных.
- Проверять исходные публикации и даты.
- Использовать собственные данные или учебные примеры.
- Исправлять неточности при появлении проверяемых сведений.
