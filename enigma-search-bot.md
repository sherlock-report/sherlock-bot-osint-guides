# ENIGMA SEARCH BOT: username, Telegram ID и запуск сервиса

**[Открыть ENIGMA SEARCH BOT →](https://probiva.bot/go/start_enigma)**

ENIGMA SEARCH BOT представлен в каталоге как направление поиска по социальным сетям, username и Telegram ID. Для первого использования важно правильно выбрать формат: имя аккаунта и числовой идентификатор — разные значения.

## Username и ID: в чём разница

Username — изменяемое имя аккаунта. Telegram ID — числовой идентификатор. Отображаемое имя профиля также не следует подменять username: это отдельное поле.

При выборе режима прочитайте его подсказку. Не предполагайте, что сервис автоматически распознаёт любые варианты ввода или преобразует один идентификатор в другой.

## Как начать

1. Откройте ссылку запуска ENIGMA SEARCH BOT выше.
2. Перейдите в Telegram и проверьте открывшийся сервис.
3. Нажмите «Старт» и изучите меню.
4. Уточните принимаемый формат выбранного режима.
5. Проверьте условия и лимиты до выполнения запроса.

Для знакомства используйте свой аккаунт или учебный пример.

## Как проверять связи между страницами

Совпадение username в социальных сетях не подтверждает общего владельца. Проверяйте публичные ссылки и контекст, а также даты сведений. Наличие числового ID тоже не означает автоматического доступа к закрытой информации.

Если результат не содержит источника связи, пометьте его как неподтверждённый.

## Частые вопросы

**Какие соцсети поддерживаются?** Проверенная карточка не содержит полного перечня. Смотрите актуальный интерфейс.

**Можно ли вводить ссылку вместо ID?** Только если выбранный режим явно принимает такой формат.

**Где узнать стоимость?** Тарифы устанавливает сам сервис; уточняйте их перед использованием.
