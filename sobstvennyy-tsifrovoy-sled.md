# Как проверить собственный цифровой след по открытым источникам

Проверка собственного цифрового следа помогает понять, какие сведения вы уже публикуете. Начинать удобно с небольшого перечня своих публичных страниц, не вовлекая в проверку чужие личные данные.

## Определите границы

Запишите свои известные username, адреса проектов и публичные профили. Выберите один вопрос: например, где сохранилось старое описание вашего проекта или какой контакт опубликован на вашей странице.

## Проведите проверку

Откройте страницы вручную и зафиксируйте наблюдения. Если используете поисковый инструмент, рассматривайте найденные ссылки как кандидатов на проверку. Убедитесь, что они действительно относятся к вашим страницам.

Для знакомства с инструментами доступен [каталог, включающий Шерлок бот](https://bot-probiva.online/). Описание карточки не заменяет проверки условий обработки введённых данных.

## Разделите результаты

Полезны три группы: сведения актуальны; сведения устарели; принадлежность не подтверждена. Последняя группа нужна для одноимённых чужих профилей — не включайте их в свой список автоматически.

## Что исправлять

Начните со страниц, которыми управляете: обновите описание, уберите ненужный контакт, уточните настройки видимости. Для чужой публикации используйте предусмотренный площадкой канал обращения.

После изменений проверьте первоисточник повторно. Результаты поиска могут некоторое время отражать прежнюю версию, поэтому дата проверки и дата исправления должны храниться отдельно.
