# Боты для пробива: критерии выбора по задаче

Выбирать боты для пробива удобнее после формулировки задачи. «Найти информацию» слишком широко. «Проверить, где встречается мой публичный никнейм» или «Оценить открытые публикации канала» позволяет сравнить возможности без лишних ожиданий.

## Составьте короткую матрицу

| Критерий | Что выяснить |
| --- | --- |
| Задача | Поддерживается ли нужный тип поиска |
| Источник | Можно ли открыть исходную публикацию |
| Актуальность | Видна ли дата наблюдения или обновления |
| Условия | Как считаются запросы и оплачивается доступ |
| Результат | Разделены ли точные данные и предположения |

Неизвестное значение записывайте как «не проверено». Не заменяйте отсутствие информации положительной оценкой.

## Сравнивайте на одинаковых условиях

Для пробного сравнения возьмите собственный публичный пример и одинаковый вопрос. Если один сервис отвечает ссылками, а другой — только текстом, оцените не объём, а проверяемость.

Два результата с одинаковыми сведениями могут происходить из одного источника. В таком случае их нельзя считать независимыми подтверждениями.

## Где начать

[Каталог ботов для пробива](https://bot-probiva.online/) помогает перейти к описаниям шести сервисов. Он не устанавливает общий стандарт качества для их ответов.

После знакомства с карточкой проверьте действующее меню. Выбирайте инструмент, который помогает решить конкретную задачу и объясняет ограничения результата. Рекламные определения «самый мощный» и «полный» без методики измерения для сравнения недостаточны.
