# Шерлок Репорт: шаблон проверки открытого источника

Ниже приведён редакционный шаблон для самостоятельной проверки публикаций. Это не образец реальной выдачи SHERLOCK BOT и не обещание наличия перечисленных полей в каком-либо сервисе.

## Карточка наблюдения

| Поле | Что записать |
| --- | --- |
| Вопрос | Один конкретный вопрос исследования |
| Наблюдение | Что непосредственно видно в источнике |
| Источник | Адрес исходной страницы |
| Дата проверки | Когда вы открыли страницу |
| Дата публикации | Если она явно указана |
| Подтверждение | Какие независимые данные поддерживают вывод |
| Ограничения | Что не удалось установить |
| Итог | Подтверждено, опровергнуто или не установлено |

## Учебный пример

Вопрос: «Есть ли описание моего проекта на публичной странице?» Наблюдение: название проекта присутствует в тексте. Ограничение: страница не сообщает, кто её обновляет. Итог: наличие упоминания подтверждено, авторство не установлено.

Такой пример показывает разницу между видимым фактом и дополнительным предположением.

## Как пользоваться шаблоном

Создавайте отдельную карточку на существенное утверждение. Не объединяйте несколько источников так, чтобы потерялось происхождение каждой детали. После повторной проверки добавляйте новую дату, а не заменяйте старую без пояснения.

## Где находится каталог

[Открыть каталог Telegram-сервисов](https://bot-probiva.online/).

В публичную версию отчёта включайте только необходимое для объяснения вывода. Для демонстрации метода подойдут собственные данные, материалы проекта или вымышленные примеры; чужие личные сведения для этого не нужны.
