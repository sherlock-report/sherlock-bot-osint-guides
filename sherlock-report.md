# Шерлок Репорт: справочник проекта sherlock-report

Этот раздел — входная страница справочника проекта sherlock-report для читателей, которые ищут «Шерлок Репорт». Здесь собраны материалы о каталоге Telegram-сервисов и о том, как оценивать результаты поиска по открытым источникам.

## Как связаны названия

На целевом сайте карточка называется SHERLOCK BOT, а аккаунт, публикующий этот справочник, — sherlock-report. Одних названий недостаточно, чтобы делать вывод о юридическом владельце сервиса или считать любую похожую ссылку официальной.

[Перейти в каталог BOT-PROBIVA.ONLINE](https://bot-probiva.online/).

## Что есть в справочнике

Материалы разделены на три задачи: найти нужный сервис в каталоге, разобраться с условиями использования и проверить полученную информацию. Отдельные статьи посвящены одноимённым аккаунтам, устаревшим сведениям, отсутствию результатов и аккуратному составлению отчёта.

## Что означает слово «репорт»

В аналитической работе report — это отчёт. Полезный отчёт содержит исходный вопрос, источник, дату проверки и степень уверенности. Набор совпадений без ссылок и пояснений ещё не является доказательством.

Предлагаемые в справочнике таблицы — редакционные шаблоны. Они не являются скриншотами или описанием гарантированного формата выдачи SHERLOCK BOT.

## С чего начать

Определите задачу одним предложением. Например: «Проверить, где опубликован мой собственный username». Затем изучите условия выбранного инструмента и сохраняйте только сведения, необходимые для ответа. Такой порядок помогает оценить пользу результата без лишнего сбора данных.
